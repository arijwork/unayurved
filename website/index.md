# Unayurved Website

Temporary website for Unayurved brand.

## How to build this site

Use the `website-build-planner` skill to guide you through the 7-phase methodology:

```
/website-build-planner
```

This will walk you through:

1. **Phase 0** — Read constraints (brand language, decisions, budget)
2. **Phase 1** — Research competitors + premium sites outside the category
3. **Phase 2** — Find the one differentiating claim, make it visual
4. **Phase 3** — Build a style tile (palette, type, buttons, interactive demo)
5. **Phase 4** — Build the full page with placeholder discipline
6. **Phase 5** — Verify like a skeptic in a real browser
7. **Phase 6** — Iterate from specific feedback, additively
8. **Phase 7** — Log every decision made
